Forecasts Grand Theft Auto VI's launch-day Twitch concurrent viewers hour by hour (hours 2–24) from the hour-1 print. A shape model fitted at run time on past rolling-midnight launches: per-hour median log-ratios across clean comparables, with cross-launch dispersion as the quantile spread. Leave-one-out pinball ~0.23 on rolling-midnight analogues, vs ~0.27 for the persistence baseline.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
